# Synthesis and Timing

The design was evaluated using Cadence Genus 21.14-s082_1 with GPDK 45 nm.

- PVT: 1.1 V, 0°C
- Balanced-tree configuration
- Area-power balance effort
- 32-bit DFF registers for A, B, and RESULT
- Real VCD activity used for switching activity analysis

Reported results:
- **11% dynamic power reduction**
- **15% cell area reduction**
- **+1550 ps setup slack**

Proprietary PDK and generated database files are not included.

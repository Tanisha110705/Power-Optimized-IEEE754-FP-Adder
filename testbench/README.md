# Testbench and Verification

Verification was performed using Cadence Xcelium and SimVision.

## Test Set

A total of **1,004 vectors** were evaluated: 1,000 random vectors and 4 corner cases.

Corner cases:
1. 0 + 1
2. 1 + 0
3. infinity + 1
4. 1 + (-1)

No functional errors were observed for the tested vectors.
